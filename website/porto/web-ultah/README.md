# Birthday Gift Website ❤️

Website kado ulang tahun mobile-first.

## Cara preview di VS Code
Disarankan memakai extension **Live Server**:
1. Buka folder `birthday-gift` di VS Code.
2. Install extension `Live Server`.
3. Klik kanan `index.html` → **Open with Live Server**.
4. Website akan terbuka di browser.

Jangan hanya mengandalkan preview editor yang tidak menjalankan JavaScript.

## Cara pakai
1. Taruh lagu MP3 di `music/lagu.mp3`.
2. Edit nama, cerita, caption, dan surat di `index.html`.
3. Upload seluruh folder ke GitHub.
4. Aktifkan GitHub Pages dari Settings → Pages → Deploy from branch.

Catatan: browser biasanya baru mengizinkan autoplay musik setelah user melakukan klik. Tombol "Buka Kadonya" menjadi trigger musik.
